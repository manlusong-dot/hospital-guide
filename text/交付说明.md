## 一、后端补全（backend/）

### 审计结论（对照 README 承诺逐项核对）
19 个 REST 接口路径与字段均与 `frontend/miniprogram/utils/api.js` 对齐，未改名未删字段；404/400 异常路径原已覆盖。真实缺口三处：

| 缺口 | 处理 |
|---|---|
| README 承诺"事件透传"（`backend/output/bridge.py` + `text/接口约定.md` + NEXT_MODULE_ENDPOINT 推送），但后端从未调用，透传逻辑为零 | 新建 `backend/api/event_pub.py` 安全薄封装，在 5 类接口接入透传：triage / journey（card·session·step）/ route / chat / registration |
| 原 bridge 推送为同步 urlopen(timeout=10)，会阻塞主请求线程最长 10s | 改写为"同步落盘 + 后台 daemon 线程 fire-and-forget 推送"，失败静默，绝不拖垮主流程 |
| README 承诺"大模型不可用自动降级知识库兜底"，但 LLM 失败时接口直接 502，兜底函数是死代码 | 接上 `_fallback_reply()`，Ollama 不在线时自动降级回答，流程推进不受影响 |

### 落地文件
- 新增 `backend/output/bridge.py` — 事件格式化（统一 envelope `{event, time, payload}`）+ outbox 落盘（文件名带 uuid 防同秒覆盖）+ 异步推送
- 新增 `text/接口约定.md` — 五类事件（triage/journey/route/chat/registration）载荷字段约定
- 新增 `backend/api/event_pub.py` — 懒加载 bridge、全程吞异常，output 出问题不影响主流程
- 接入改动：`backend/api/{guide,journey,navigate,chat,demo}.py`；降级修复 `backend/ai_core/guide_engine.py`
- 实测样例：运行时写入 `backend/output/outbox/*.json`（不随项目提交）

### 端到端实测（本机独立复测）
- `init_db.py` 建库成功：floors=4 / nav_nodes=218 / nav_edges=239 / departments=28 / exam_prep=9 / medicine_guide=8 / doctors_demo=410
- uvicorn 启动成功，`/docs` 200，openapi 共 19 条路径
- 实测通过：triage（200，主科室+备选）、departments(28)、journey/card（12 步流程卡）、session/step/查询、navigate（主入口→内科门诊(一区)，distance_m=167.1，跨楼层 segments）、chat（真实命中本地 Ollama 返回，3.3s）、chat/history、demo/doctors、demo/register（返回 registration_id）、demo/registrations（含医生/科室/楼层联查）
- 异常路径：不存在科室→404、空症状→400、不存在医生→404、不存在会话→404
- 事件透传实测：设 `NEXT_MODULE_ENDPOINT=http://127.0.0.1:9000/events` 后，五类事件全部按 接口约定.md 格式实时送达，outbox 同步落盘

### 运行方式
```
pip install -r backend/api/requirements.txt
python backend/database/init_db.py
python -m uvicorn backend.api.main:app --reload   # http://127.0.0.1:8000/docs
# 可选：设置 NEXT_MODULE_ENDPOINT=http://你的地址/xxx 开启实时事件推送
```

## 三、小程序 UI 改造（frontend/miniprogram/，简洁 iOS 风）

### 设计
按 doubao-creative-design skill 流程产出视觉规范：**`text/DESIGN-IOS.md`**
- 原则：系统级扁平、层级干净（灰底→白卡→分组）、克制用色、适老化可读性保留
- 配色 token：主色 iOS 系统蓝 `#007AFF`；分组灰底 `#F2F2F7`；文本 `#1C1C1E/#3A3A3C/#6D6D72`（灰字加深至对比度≥4.5:1）；语义色 `#FF3B30/#FF9500/#34C759`
- 字体层级：large-title 56rpx → footnote 28rpx；正文下限 32rpx、hint 下限 28rpx、按钮高 96rpx、行高≥1.5
- 组件规范：导航栏、tabBar、卡片、主/次/危险按钮、分组表单、列表 cell、pill 标签、分段控件、聊天气泡、底部输入栏、首页网格、步骤时间线

### 落地（7 页 + 全局，仅 UI 层，JS 逻辑与接口调用零改动）
| 文件 | 改动 |
|---|---|
| app.wxss / app.json | 全局 token 重写；导航栏 #F2F2F7、tabBar 选中 #007AFF |
